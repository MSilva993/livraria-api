# API de Biblioteca

Este projeto contém uma API simples em formato **JSON** para manipulação de livros, além de uma página **HTML** que consome esses dados e exibe uma lista de títulos.

## Estrutura do projeto
- **api.json** → Arquivo com os dados da API (metadados e lista de livros).
- **index.html** → Página que consome o `api.json` usando `fetch` e exibe os livros.

## Funcionalidades
- Listagem de livros com título, subtítulo e preço.
- Estrutura pronta para ser publicada em **Azure Static Web Apps**.
- Exemplo simples para estudos de consumo de APIs em aplicações front-end.

## Tecnologias utilizadas
- **HTML5**
- **CSS3**
- **JavaScript (fetch API)**
- **JSON**
